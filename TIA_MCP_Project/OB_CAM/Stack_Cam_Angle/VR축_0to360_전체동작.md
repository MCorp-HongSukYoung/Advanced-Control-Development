## 0) 한 줄 결론

> **VR03 1회전(0°→360°) = 4-Phase 사이클 중 RUN Phase 1회.**  
> LC_RUN과 RA_RUN이 각각 VR03을 1회전시키며, P&P 12축 + Reverse 4축 + Stack Table Swing 4축이 VR03 슬레이브로 동기된다. Reverse R/Z는 GET(20°~180°)·PUT(180°~340°)·Dwell(나머지) 세 구간으로 나뉘어 동작한다.

## 1) 4-Phase 사이클 전체 구조

```
[LC_RUN] → [LC_STACK] → [RA_RUN] → [RA_STACK]  × N층
  VR03↑       VR04↑       VR03↑       VR04↑
```

| Phase | 마스터 | 주 동작 | Reverse 역할 |
|-------|--------|---------|-------------|
| **LC_RUN** | VR03 | Cathode PUT + Anode GET | Cathode Reverse PUT(180°~340°) / Anode Reverse GET(20°~180°) |
| **LC_STACK** | VR04 | Mandrel Cathode 전극 압착 | CAM 비활성 |
| **RA_RUN** | VR03 | Anode PUT + Cathode GET | Anode Reverse PUT(180°~340°) / Cathode Reverse GET(20°~180°) |
| **RA_STACK** | VR04 | Mandrel Anode 전극 수령·압착 | CAM 비활성 |

> VR01/VR02(Dsheet 검출)는 4개 Phase 내내 상시 회전.

## 2) 동작 구조 (LC_RUN 기준)

```
          [ FB_Auto_Sub1_Stack_200 ]
                     │
                     │  MC_MOVERELATIVE(VR03, +360°)
                     ▼
     ┌──────────────────────────────────┐
     │   VR03_StackLeadingAxis  0→360°  │  ← 가상 마스터
     └──────────────────────────────────┘
                     │
    ┌────────────────┼──────────────────┐
    ▼                ▼                  ▼
[ Cathode P&P ]  [ Anode P&P ]    [ Stack Table ]
─ 메인 1/2 X·Z   ─ 메인 1/2 X·Z   ─ Swing Roller Z01/Z02
─ Reverse  Z·R   ─ Reverse  Z·R   ─ Swing Roller R01/R02
```

VR03은 물리 인코더 없는 가상축으로, `FB_Auto_Sub1_Stack_200`의 sub-step 230에서 `MC_MOVERELATIVE`로 한 바퀴 돌린다. 그 한 바퀴 동안, `FB_Camin_STACK_LC_RUN`이 미리 결합해둔 25개 슬레이브가 캠 프로파일을 따라 동작한다.

> **InSync 조건**: Reverse R/Z의 `CamIn.InSync`도 `STACK_LC/RA_RUN_InSync` 조건에 AND 포함 — Reverse 동기 실패 시 Phase 전환 차단.

### 비전 트리거 교정 근거

LC_RUN에서 **RA Vision이 먼저(80°), LC Vision이 나중(170°)** 트리거되는 이유:

```
LC_RUN (VR03 회전 중)            RA_RUN (다음 Phase)
  80°  → RA Vision 사전 검사  →  RA_RUN 시작 시 검사 데이터 준비 완료
  170° → LC Vision 검사        →  이번 LC 전극 품질 확인 완료
```

반대로 RA_RUN Phase에서는 **LC Vision이 80°, RA Vision이 170°** 에 트리거됩니다(`FB_Auto_Sub1_Stack_300` 확인).  
각 Phase가 **상대방 Vision을 먼저 쏘는 교차(Cross) 구조**로 다음 Phase 시작 전 검사 데이터를 미리 준비합니다.

### 한 사이클 안의 두 파이프라인

```
[ LC 전극 흐름 ]
매거진 ─▶ LC PP1(픽업) ─▶ Reverse Table(반전+Surface Vision) ─▶ AlignTable(직접 전달)

매거진 ─▶ RA PP2(픽업) ─▶ Reverse Table(반전+Surface Vision) ─▶ AlignTable(직접 전달)
                                                                        │
                                                                  Align Vision
                                                                        │
                                                              RA PP1(픽업) ─▶ Stack Table ─▶ Gap Vision
```

> 두 흐름은 **VR03 한 바퀴 동안 동시에 진행** (2-단 파이프라인).  
> **이번 사이클에 적층되는 전극 = 이전 사이클 Reverse 완료 전극**.  
> **이번 사이클 GET 전극 = 다음 사이클에 적층**.

> 두 파이프라인은 **VR03 한 바퀴 동안 동시에 진행**.  
> **이번 사이클에 적층되는 전극 = 이전 사이클 Reverse 완료 전극**.  
> **이번 사이클 GET 전극 = 다음 사이클에 적층**.

## 9) 각 흐름 서술

### 9-1. LC (Cathode) — `PP1 → Reverse Table → AlignTable → PP2 → Stack Table`

> CAM export + FB_Camin_STACK_LC/RA_RUN + FB_Auto_Sub1_Stack_200 코드 기반.  
> 파이프라인 구조이므로 각 단계는 서로 다른 VR03 사이클(Phase)에서 진행됨.

| # | 동작 | Phase | VR03 각도 |
|---|---|---|---|
| 1 | **매거진 픽업** `LC PP1`(Axis13/14) — Z 최저 = 흡착 | LC_RUN | **VR03 = 180°** |
| 2 | **Reverse Table 전달** `LC PP1` — Z 최저 = 안착, VAC 전환 | RA_RUN | **VR03 = 180°** |
| 3 | **LC Surface Vision** `DB_1st/2nd_Surface_Vision_LC` 트리거 | RA_RUN | **VR03 ≥ 170°** |
| 3′| **RA Vision 사전 준비** `DB_1st_Surface_Vision_RA` 트리거 | RA_RUN | **VR03 ≥ 80°** |
| 4 | **Reverse 반전** `ReverseR_GET`(Axis12) R 이동 — 전극 수신 후 회전 | RA_RUN | **VR03 = 20°~180°** |
| 5 | **AlignTable 직접 전달** `ReverseZ_PUT`(Axis11) Z 최저 = 안착, VAC 전환 | LC_RUN | **VR03 = 252°~274°** |
| 6 | **Align Vision** `DB_Align_Vision` | LC_RUN | 252°~274° 이후 |
| 7 | **Stack Table 전달** `LC PP2`(Axis15/16) — Z 최저 = 안착 | LC_RUN | **VR03 = 180°** |
| 8 | **Gap Vision** `DB_Gap_Vision_LC` | LC_RUN | 180° 이후 |

> **Phase 주의**: 1번(매거진 픽업)과 7번(Stack Table 전달)은 같은 LC_RUN이지만 서로 다른 사이클 — 한 전극이 매거진을 떠나 Stack Table에 도달하기까지 LC_RUN → RA_RUN → LC_RUN 3개 사이클을 거침.

```
LC_RUN (사이클 N)    RA_RUN (사이클 N)    LC_RUN (사이클 N+1)
────────────────────────────────────────────────────────────
① PP1 매거진 픽업    ② PP1 Reverse 전달   ⑤ Reverse→Align 전달
   (180°)              (180°)               (252°~274°)
⑦ PP2 Stack 전달    ③ LC Vision 확인      ⑥ Align Vision
   (180°)              (≥170°)
                    ④ Reverse 반전
                       (20°~180°)
```

### 9-3. Stack Table Swing Roller — 분리막 덮기

> 실측 CAM export 기반 (Cam_STACK_Swing1Z_LC, Cam_STACK_Swing1R_LC).

1. **0°~72° · 압착**: Z 하강 (0→1, CubicSpline) — 롤러가 분리막에 압착. R은 36°까지 홈 유지.
2. **36°~288° · 스윕**: R 회전 (0→1, CubicSpline) — 분리막을 전극 위로 밀어 씌움. Z는 72°~288° 완전 압착 상태 유지.
3. **288°~360° · Z 복귀**: Z 상승 (1→0) — 롤러 들어 올림. R은 324°에 완전전개 도달 후 360°까지 유지.
4. **STACK Phase · 홈 복귀**: CAMOUT 후 Z·R 양축 모두 홈 복귀 (CAM 내에서는 복귀 없음).
